kQSO — privacy policy

Applies to the kQSO apps for Android and iOS (iPhone, iPad) and the web app at kqso.ok1cdj.com. Last updated 2026-10-07.

Your data stays on your device

Logs, QSOs, the callsign database and settings are stored only on your device (Android: files in the app's storage; iOS: the app's Documents folder, which you also see in the Files app; web: the browser's private storage). kQSO has no account, no server of its own for your data, no ads and no analytics in the app.

When kQSO uses the network

  • Wavelog push — only when you tap it: the log is sent to the Wavelog server you set up, with your own API token.
  • Rain radar — only when you switch it on (off by default): map tiles are loaded from RainViewer (api.rainviewer.com, tilecache.rainviewer.com). They see your IP address and the map area, never any log data.
  • New-version check — Android app installed from GitHub only, at most once a day, switchable in Settings: asks the GitHub API for the latest release. Not done when the app comes from Google Play, and never in the iOS app (the App Store keeps it up to date).
  • Web app statistics — the web app (not the Android or iOS app) counts anonymous screen views and a few action names on a self-hosted Umami server (stats.ok1cdj.com), without cookies and never with log content. Switchable in Settings.

Permissions

  • Bluetooth — only to connect the CW keyer (M5-ESP32-keyer) or an Icom IC-705, when you switch that on and tap Connect.
  • Location — only on Android 11, where the system requires it for a Bluetooth scan; the iOS app does not ask for it. kQSO never reads your position; your locator is what you type.
  • Internet — for the uses listed above.

kQSO — zásady ochrany soukromí

Platí pro aplikace kQSO pro Android a iOS (iPhone, iPad) a webovou aplikaci na kqso.ok1cdj.com. Aktualizováno 2026-10-07.

Data zůstávají v zařízení

Logy, QSO, databáze značek i nastavení jsou uložené jen ve tvém zařízení (Android: soubory v úložišti aplikace; iOS: složka Dokumenty aplikace, kterou vidíš i v aplikaci Soubory; web: soukromé úložiště prohlížeče). kQSO nemá účet, nemá vlastní server pro tvoje data, nemá reklamy ani analytiku v aplikaci.

Kdy kQSO používá síť

  • Odeslání do Wavelogu — jen když na něj klepneš: log jde na server Wavelogu, který si nastavíš ty, s tvým vlastním API tokenem.
  • Srážkový radar — jen když ho zapneš (výchozí vypnuto): dlaždice mapy se načítají z RainViewer (api.rainviewer.com, tilecache.rainviewer.com). Vidí tvoji IP adresu a oblast mapy, nikdy data z logu.
  • Kontrola nové verze — jen aplikace pro Android nainstalovaná z GitHubu, nejvýš jednou denně, vypínatelná v Nastavení: zeptá se GitHub API na poslední vydání. Neprobíhá, když je aplikace z Google Play, a nikdy v aplikaci pro iOS (aktualizuje ji App Store).
  • Statistiky webové aplikace — webová aplikace (ne aplikace pro Android ani iOS) počítá anonymní zobrazení obrazovek a několik názvů akcí na vlastním serveru Umami (stats.ok1cdj.com), bez cookies a nikdy s obsahem logu. Vypínatelné v Nastavení.

Oprávnění

  • Bluetooth — jen pro připojení CW klíčovače (M5-ESP32-keyer) nebo rádia Icom IC-705, když to zapneš a klepneš na Připojit.
  • Poloha — jen na Androidu 11, který ji vyžaduje pro vyhledávání Bluetooth; aplikace pro iOS o ni nežádá. kQSO tvou polohu nikdy nečte; lokátor je ten, který napíšeš.
  • Internet — pro použití uvedená výše.
